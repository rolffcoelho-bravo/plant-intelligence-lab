# B14A official 2024 source note

The official Genomes to Fields resources page lists the 2024 Maize Genotype by Environment Prediction Competition release under DOI `10.25739/78mn-4394`.

The associated 2024 competition data note lists the test-side files separately, including:

- `1_Submission_Template_2024.csv`
- `2_Testing_Meta_Data_2024.csv`
- `3_Testing_Soil_Data_2024.csv`
- `4_Testing_Weather_Data_2024_full_year.csv`
- `4_Testing_Weather_Data_2024_seasons_only.csv`
- `6_Testing_EC_Data_2024.csv`
- `7_Testing_Observed_Values.csv`

The data note reports 1,063 test hybrids across 23 test locations. B14A stages only the submission template and testing metadata. It does not stage the observed-values file and does not import the release's 2,425-SNP genotype representation.

This note records source structure only. The actual B14A compatibility decision must come from the locked repository audit and its source checksums.
